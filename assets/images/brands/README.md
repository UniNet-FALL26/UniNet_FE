# Brand assets

- `github.svg`: GitHub mark from Primer Octicons (MIT), https://github.com/primer/octicons/blob/main/icons/mark-github-16.svg
- `linkedin.svg`: LinkedIn mark from Bootstrap Icons (MIT), https://github.com/twbs/icons/blob/main/icons/linkedin.svg
- Both SVGs are stored locally and rendered by assessor profile link cards in their brand colors.

- `tiktok.png`: unmodified `TikTok_Icon_Black_Square.png` from TikTok's official developer logo pack. Rendered locally by `WebsiteBrandIcon` for TikTok profile links.
- Source guidelines: https://developers.tiktok.com/doc/getting-started-design-guidelines
- Asset pack: https://sf16-va.tiktokcdn.com/obj/eden-va2/uvzhqeh7nuhd/tt4d/logo-pack.zip
