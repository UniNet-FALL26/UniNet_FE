# Profile interests editing

- Spec: `docs/specs/profile-interests-editor.md`. Editor “Thêm sở thích cá nhân” opens `ProfileInterestsPicker`; search supports Vietnamese without accents, 48 checkbox options, selection count, clear, cancel and apply. Apply updates the existing profile draft; Save profile persists it with existing failure/retry and unsaved-change handling.
- All three templates render `ProfileInterests` for real profiles. Empty sections hide for viewers and show an add action in the editor. Existing hidden-section settings remain authoritative.
- Shared frontend options/icons: `src/data/profile-interests.ts`; backend validation catalog: `UniNet.Application/Common/PortfolioInterestCatalog.cs`. Update both when adding options. Sample JSON and frontend catalog consistency have regression coverage.
- API: existing owner portfolio/editor endpoints accept optional `interests`. JSON storage uses `CareerProfile.BasicInfoJson`, with no migration. Missing/null preserves existing interests for older clients; `[]` clears them. Responses expose an array. Backend rejects invalid names, null/blank entries, duplicates and more than 48 selections. Visitor/application snapshot filtering handles `interests`.
- Verification: 57 existing/new portfolio tests plus an additional HTTP authorization/round-trip test; frontend catalog test and 26 editor/draft/field/preview regression tests. Preview browser suite passes at 1440/375/320px. Editor browser suite covers three templates at desktop/320px, search, cancel, multi-select, failed save/retry, reload, visitor display and clearing. Screenshots: `dist/profile-interests-editor/`.
- New frontend components/catalog pass ESLint and have no TypeScript diagnostics. Full typecheck retains existing `opportunities.tsx` / `AssessorProfilePosts.tsx` errors. Shared editor/context retain pre-existing effect/ref lint diagnostics outside the changed lines.
