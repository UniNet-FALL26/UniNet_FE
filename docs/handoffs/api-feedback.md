# Shared API action feedback

- `apiRequest` and `apiMultipartRequest` wrap their original implementations with centralized feedback; session refresh, bearer handling, response values and multipart boundaries remain intact. Mutations show action-specific success. GET success, auth refresh, unread-count polling and intermediate uploads stay quiet. Aborted requests do not notify; stale-session requests never notify success.
- `utils/api-feedback.ts` extracts Vietnamese API messages and validation dictionaries, translates known business codes and provides contextual HTTP fallbacks. Raw codes, English transport errors, stack traces and database diagnostics are excluded from visible messages. `ApiError.code/status` remain available internally. Existing project translations retain dynamic limits.
- `toast.store.ts` keeps one active notification and resets its 3000ms timer when replaced; outdated dismissals cannot clear a newer result. `ToastHost` animates from above, overlays content without shifting it and supports modal hosts so photo/profile/community/settings errors remain visible on native. Highest active modal owns rendering; root resumes when it closes.
- `ApiRequestOptions.feedback` can disable both notifications (`false`) or customize success/disable error. `reportApiFailure` handles local failures without repeating already-emitted API errors. `ActionFeedback` redirects existing transient result state instead of keeping inline banners.
- Migrated profile/photo/editor/settings/community feedback, partner verification and job-publish notices, ad errors, project edit/confirmation hosts, and report-file transport errors. Field validation, data-loading retry states, confirmation dialogs and payment/status instructions remain available.
- Validation: 8 deterministic checks in `node tests/api-feedback.test.cjs` cover timer/reset, localization, API contracts, multipart, cancellation/session guards and project-limit preservation. `node tests/api-feedback-browser-check.cjs` checks both roles, top placement/3-second dismissal and success/business/validation/server/network/logical failures with fixtures. Partner photo upload and profile browser regressions pass. `npx tsc --noEmit` and diff whitespace checks pass. Native modal host behavior is implemented; runtime visual verification was performed in Chrome.
