# Recruitment and application icons

Use `src/constants/job-applicant-icons.ts` as the shared icon map for partner job management and student opportunity/application screens. Keep the meaning consistent wherever the same information appears:

- Job and work mode: briefcase and building.
- Employment type: clock.
- Job field: category grid.
- Location: map pin.
- Salary: banknote / payments.
- Application deadline: calendar.
- Last updated: refresh.
- Applicant count: people.
- View count and CV preview: eye.
- Job description: document; requirements: checklist; skills: chart.
- Benefits section heading: sparkles, so it does not duplicate any selectable benefit icon.
- Application status action: sync arrows.

Keep each benefit item's own selected icon separate from the section heading icon.
